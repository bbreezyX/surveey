# Arsip pengusul

Salinan file dari `master` (per commit 27c4ad4, 6 Oktober 2026) yang memuat
nama orang: nama pengusul, petugas, atau warga. Di `master` file-file ini
dihapus atau namanya dibuang, supaya tidak ada nama orang di repo publik
utama maupun di peta.

- `scripts/` — skrip impor per pengusul (append_hafiz_*, apply_rekapan,
  place_siulak_gedang) dan versi lengkap normalize_attributes (NAMA_FIXES),
  build_titik_berdekatan (dengan kolom Pengusul).
- `docs/titik-berdekatan.csv`, `docs/titik-tumpuk.csv` — versi lengkap
  dengan kolom Pengusul / Nama Anggota.
- `Sebaran Titik M Hafiz.txt` — rekap sebaran per pengusul.
- `../data/pengusul.csv` — nama pengusul per titik (Nomor).
